# 0.4.12 发布与分发验证

## 发布原因与提交

本次维护把运行依赖 Zod 从 4.6.5 更新至 4.6.7，需要新 npm 版本才能向安装用户交付。0.4.12 同时包含依赖 PR [#9](https://github.com/takboo/dsh-usage-state/pull/9) 的重建产物，以及 [#18](https://github.com/takboo/dsh-usage-state/pull/18) / [#17](https://github.com/takboo/dsh-usage-state/pull/17) 的 rc.4 / alpha.2 精确回归矩阵与原始证据。三个 bundle 相对0.4.11的差异仅为构建工具生成的文件边界注释；alpha.2 为回归候选，宿主支持声明未扩大。

发布准备 [#19](https://github.com/takboo/dsh-usage-state/pull/19) 同步 package/lock 根版本、双语 README 与带日期 Changelog。稳定 tag [v0.4.12](https://github.com/takboo/dsh-usage-state/releases/tag/v0.4.12) 指向 `80bc8cfa4839e32f17d07d12d95ce5b1b0b5a2c8`。

## CI 与发布工作流

- 规范 Node24.21.0/npm11.19.1 的干净提交 `npm run verify` 通过385项测试、类型检查、构建、HEAD三个bundle一致性、12文件打包白名单与包内链接校验。
- [发布 PR CI](https://github.com/takboo/dsh-usage-state/actions/runs/41380684657) 与 [最终发布 main CI](https://github.com/takboo/dsh-usage-state/actions/runs/41380851477) 的11项检查全部通过：Node22.18开发下界、Node24规范打包、Node20预构建运行，以及 rc.1/rc.2/rc.3/rc.4/rc.5/alpha.2 精确RPC契约。
- [tag自动派发](https://github.com/takboo/dsh-usage-state/actions/runs/41380991542) 成功；[Release run 41381000289](https://github.com/takboo/dsh-usage-state/actions/runs/41381000289) 的可信tag验证、单次打包、同包Node20冒烟、npm OIDC发布和GitHub附档全部成功。
