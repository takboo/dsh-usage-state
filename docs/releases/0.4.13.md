# 0.4.13 发布与分发验证

## 修复与审查

本次修复供应商路由 `sub2api-kimi`、`sub2api-glm` 被模型厂商关键词优先匹配为官方来源的问题。Sub2API 网关提示现在优先于模型厂商名；手动来源覆盖、隐藏和模式选择共同用于凭据发现，避免请求已切到 Sub2API 而凭据仍按 Kimi 分类。

provider 声明的端点原本已经传入后端请求；设置页的必填警告却只检查手动覆盖。现在输入框提示有效的继承地址，并说明留空继续复用；仅在最终地址缺失时要求填写。端点仍只向浏览器暴露 origin，不新增凭据内容。

审查未发现本次改动的阻断问题。补充设置交互回归，验证清除覆盖恢复继承、继承地址不会写回覆盖字段，以及再次填写覆盖后的行为。发布提交同时包含修复、测试、双语说明、版本与三个 bundle 的重建结果。

稳定 tag [v0.4.13](https://github.com/takboo/dsh-usage-state/releases/tag/v0.4.13) 指向 `a04c6b1f0b5020818ec74b2f4013a3daabb903b4`。

## 已知边界

本次未扩大DSH支持范围；alpha.2仍为回归候选。没有新增真实Desktop账号钱包、厂商余额请求、凭据保存落盘、模型推理或完整视觉验收；已有隔离Web证据见 [0.4.11](0.4.11.md)，未完成项目继续见 [Backlog](../backlog.md)。

`npm ci` / `npm audit` 报告现有宿主peer链 `@deepseek-ai/dsh-settings → dsh-config-editor → dsh-app-boot → ajv → fast-uri@3.1.8` 的一项moderate包告警（包含 [scheme spoofing](https://github.com/advisories/GHSA-w74x-v6f9-j3xg) 等advisory）。该锁定条目与发布基线相同；`fast-uri` / `ajv` 未打入本插件bundle，插件直接运行依赖仍仅为Zod4.6.7。本次不宣称修复宿主peer依赖告警，宿主依赖链需另行维护。
