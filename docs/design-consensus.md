领域词汇见 [术语表](../CONTEXT.md)，实现见 [架构](architecture.md)，未完成验收见 [待办](backlog.md)。历史决策过程已移入 [归档](archive/design-changelog.md)。

## 范围

显示当前模型供应商路由对应账户的余额或套餐额度。配置单元是provider，模型清单仅供参考；账户读数可能包含多个模型、会话与客户端的使用。

只显示当前读数，不做回合成本归因、价格目录、账本、预算或历史面板。状态行只挂载 `conversation.input.dock`，保留原生统计和上下文计量器；不向会话日志追加自有事件。

## 来源与模式

- `api`：以API Key查询账户余额；`account`：通过Harness当前登录账户查询余额；`coding-plan`：查询套餐窗口。`auto`和`hidden`是配置选择。
- DeepSeek `deepseek-account` 自动使用账号余额；`deepseek-official` 使用API Key余额。账号服务负责登录、目的地址、超时与失效；账号模式忽略API Key/端点覆盖，不回退到API Key。
- Kimi Code路由及官方Code端点自动使用套餐模式，Moonshot使用余额模式。其他来源按目录能力选默认模式，显式配置优先。
- 路由ID包含Sub2API时优先识别为网关来源，其中的Kimi、GLM等模型厂商名不改变余额来源；实际端点为官方 `api.openai.com` 时只显示其接口限制，不探测网关余额协议。手动来源覆盖同样用于凭据发现；未覆盖接口地址时复用供应商声明端点的origin，设置页显示继承地址，仅在有效地址缺失时要求填写。
- OpenAI官方 API Key 仅识别来源并显示余额查询能力限制及官方账单入口；普通 API Key 没有文档化的当前余额接口，不解析凭据、不轮询或构造零余额。Admin Usage/Costs历史消费、浏览器会话token与速率限制均不替代余额。第三方OpenAI兼容平台按实际端点和余额协议识别，不因OpenAI名称或模型视为官方来源。
- 当前每个source+mode只保留一个目标，由首个有效provider拥有；不据厂商同名断言不同密钥或实例属于同一账户。

## 身份与隐私

API Key显式provider覆盖、旧source覆盖优先；自动发现只读取目标owner在同一origin声明的凭据名，不聚合同来源其他provider的候选。仅在owner未声明凭据名时，适配器默认凭据名才用于其内建官方origin/镜像；已声明的owner凭据缺值时不再退回默认密钥。自定义origin需同一owner声明或显式覆盖。宿主凭据服务的回答优先；服务不可用时的直接回退与版本差异见 [平台说明](platform-notes.md)。账号模式只在Host中使用登录grant的摘要隔离身份，原始grant不进入API Key字段、RPC、配置和错误详情。

端点、ref、有效凭据或登录身份改变后清旧值；代次检查阻止晚lookup、晚HTTP或旧RPC恢复旧身份。失败只保留同身份成功值，并显示年龄和原因。RPC只传归一化读数、来源元数据和origin-only提示；秘密和私有身份摘要留在Host。

## 数值与展示

余额使用厂商明确的主单位和币种；非法金额不能冒充零。DeepSeek账号余额为同币种充值与赠送余额之和，赠送/充值拆分保留在提示中。窗口百分比表示已用，只有来源实际返回的窗口才展示。

当前模型决定状态行读数。未选择模型、隐藏或槽位未开放时可不显示。悬浮提示包含来源、模式、余额构成、重置和失败信息；语言随DSH设置。

## 刷新与配置

宿主默认回合结束2秒后刷新、空闲5分钟刷新；成功请求最小间隔60秒，显式force可绕过。浏览器30秒读取镜像，普通轮询只初始化缺失或身份变化的读数；修改idle配置重调timer。

配置由DSH configForms/volatile保存。旧models仅经normalize迁移，不保留平行轮询路径。配置写权限与凭据写权限分别判断；异步写入拒绝、pending和失败需要可见。

## 验证与交付

源码、三个预构建入口及包清单一同提交。源码测试、真实registry契约、tarball独立安装、实际浏览器和真实账户是独立证据。发布遵循 [发布流程](release.md)，未完成的真实验收保留在待办清单。
