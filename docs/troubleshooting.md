# 用户排查

适用于DSH0.2及0.4系列。**npm已发布0.4.4不含本轮修复；以下当前行为指本地Unreleased。** 安装与使用见 [中文README](../README.md) / [English](../README.en.md)。记录安装来源、提交或tgz校验值，不能仅据同样的0.4.4版本号区分产物；整改与验证状态见 [Backlog](backlog.md)。

## 先检查这四件事

1. DSH版本满足 `>=0.2.0-rc.2 <0.3.0-0`，插件安装到实际正在使用的web profile。
2. 安装或修改宿主后已经重启DSH。插件patch在启动时读取。
3. 当前会话已选择模型，供应商未选择隐藏。新会话未选择模型时，状态行可以不显示。
4. 打开“设置→用量状态”，查看供应商、解析数据源、凭据来源和错误消息。

DSH0.1使用历史版本0.3.2；它不适配0.2。0.4.0存在RPC挂载缺陷，应升级至最新兼容版，不要停在0.4.0。

## 没有读数或状态异常

| 症状 | 检查与处理 |
|---|---|
| 设置页/整行都没有出现 | 确认profile、重启、插件未在启动恢复中被禁用；开发安装确认预构建文件存在 |
| 一直“读取中”或报remote挂载失败 | 查客户端控制台/宿主日志；入口出现不代表RPC贡献已挂载。维护者按 [发布验收](release.md) 核对真实registry |
| “未配置”，但DSH中已有key | 核对来源/ref与实际加载产物；本地RPC已传origin提示供两UI识别。未知来源仍可显式选择数据源；若是npm0.4.4，参见下表A08旧缺口 |
| 自建源提示缺接口地址 | 高级区填写所用实例地址；不会为Sub2API猜一个默认站点 |
| “密钥无效” | 检查key所属产品/区域。z.ai国内与国际key不通用；固定端点后不会用镜像替代选择，OpenCode Go仍需对应订阅 |
| 环境key输入框不可编辑 | 环境值优先；修改启动环境并重启。配置只读与key权限独立判断，显式ref的候选状态决定是否可写 |
| 旧值+⚠ | 同身份源失败保留旧值；悬停标签查看年龄/具体原因，设置页有失败详情 |
| RPC断线 | 本地会标陈旧/年龄及连接失败；恢复连接后重试。配置身份变化则清旧值，不能靠旧数字确认新账户已生效 |

`env (direct)`/`file (direct)` 表示插件用了直接读取兜底，不表示密钥上传到了浏览器。凭据位置是DSH home下的凭据文件，不一定是默认 `~/.dsh`。请勿在issue中粘贴该文件内容或完整日志里的密钥/token。

## 当前版本需要注意的操作

本表左侧旧行为仍存在于 **npm已发布0.4.4**；右侧是当前 **Unreleased**，尚未npm交付。先确认产物来源再判断是否复现了本地缺陷。

| 操作或结果 | npm0.4.4旧行为 | 当前Unreleased |
|---|---|---|
| 指定凭据名 | [A01](backlog.md#a01) 覆盖不进入请求 | ref贯通读取/描述，保存优先显式ref |
| 固定z.ai端点 | [A03](backlog.md#a03) 失败仍可能镜像 | 保留pin，401也不试镜像 |
| 切端点/ref或轮换key | [A04](backlog.md#a04) 旧缓存/在途可复原旧身份 | 清旧值并拒绝过期代次，不能作为多账户支持 |
| legacy配置后隐藏 | [A05](backlog.md#a05) 仍可能后台请求 | models只迁移；隐藏/权威空目录不轮询 |
| 默认供应商↑↓ | [A09](backlog.md#a09) order为空时无效 | 按可见顺序保存 |
| 修改idle间隔 | [A06](backlog.md#a06) timer不重调，poll缩短频率 | live重调，30s普通poll仅初始化缺失/变更身份 |
| Moonshot金额≥100元 | [A02](backlog.md#a02) 被除以100 | 官方元单位；仍可与 [官方接口](https://platform.kimi.com/docs/api/balance.md) 对照 |
| DeepSeek突然0 | [A07](backlog.md#a07) 畸形金额可能造0 | 合法0保留，非法读数报parse并保留同身份旧值 |
| 保存/清除失败 | [A16](backlog.md#a16) 拒绝/只读反馈不完整 | false/rejection可见，凭据操作pending防重复，配置/key权限分开 |

Kimi Code/Sub2API真实账户、高阈值颜色、真实DSH凭据写入和OpenCode非零仍缺活体验证。本地交互回归通过不等于已执行这些真实操作。

## 恢复与报告问题

停用或卸载前确认使用的是目标profile：

```bash
dsh plugin --profile web remove dsh-usage-state
```

重启DSH使patch变化生效。需要使用其他profile时换成实际名称。

[提交issue](https://github.com/takboo/dsh-usage-state/issues)时提供：插件/DSH版本、安装来源、provider id、所选模式、是否自定义端点、脱敏错误和复现步骤。不要提交密钥值、完整凭据文件、会话内容或带登录token的URL；截图可只保留用量状态区域。
